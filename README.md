# YouTube video downloader

Инструмент для загрузки видео с YouTube в различных форматах.

## Технологии

![Python](https://img.shields.io/badge/-Python-F9DC3E.svg?logo=Python&style=flat)
![PyQT5](https://img.shields.io/badge/-PyQt5-41CD52?logo=qt&&logoColor=white)
![PyTube](https://img.shields.io/badge/-PyTube-EE4C2C)

## Возможности

- Загрузка видео и плейлистов
- Выбор формата загрузки
- Отображение информации и видео
- Сохранение истории загрузок

## Установка

```bash
git clone https://github.com/AlekseevValeriy/youtube-video-downloader.git
cd youtube-video-downloader
```

## Использование

```bash
cd code
python main.py
```
